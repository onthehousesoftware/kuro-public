Parents' guide

Kuro makes figures with an AI account that you own, so nobody else pays for them and nobody else sees your keys. Setting one up takes about 5 minutes. A grown-up should do these steps.

Pick one to start. You can add the other later.

Free: connect a Cloudflare account

A free Cloudflare account makes about 100 figures a day. It needs no card. When the day's figures are used up it simply stops until the next day, and Kuro tells you the time they come back.

  1. Go to dash.cloudflare.com/sign-up and make a free account. Open the email Cloudflare sends and verify your address.
  2. In the Cloudflare dashboard, open Workers AI (under AI in the menu on the left), then select Use REST API.
  3. Select Create a Workers AI API Token. Look over the details it fills in, select Create API Token, then Copy API Token. Cloudflare only shows the token once, so paste it into Kuro (step 5) before you close the page.
  4. On the same page, under Get Account ID, copy the Account ID. It's 32 letters and numbers.
  5. In Kuro, open Settings. Under Your Cloudflare account, paste the account ID and the token, tap Test connection, then Save.

Making the token yourself instead of with Cloudflare's button? Give it only Workers AI · Read and Workers AI · Edit, for this one account. Nothing else is needed.

Paid: add a Gemini key

Google's Gemini can look at up to 3 of your starred drawings, so figures come out closer to the artist's own style. It costs about 4¢ a figure from credit you add ahead of time. When the credit reaches $0 it stops, so there's no surprise bill.

  1. Go to aistudio.google.com and sign in with a grown-up's Google account.
  2. Select Get API key, then Create API key. Copy the key.
  3. Open Billing in AI Studio and set up prepaid credit. The smallest amount is $10. You only pay what you add.
  4. In Kuro, open Settings. Under Gemini API key, paste the key and tap Save key. Kuro checks it with Google first.
  5. Type the amount you added in Gemini credit balance and tap Set balance. Kuro counts down from there as an estimate. AI Studio's Billing page always has the exact number.
  6. In the Library, star up to 3 drawings with Use as a style example.

If you connect both, Kuro uses Gemini first and switches to your Cloudflare account by itself when the Gemini credit runs out.

Install Kuro

Kuro works in the browser, and installing it puts it on the home screen like any other app. It still works offline for the library and timer.

Android

In Chrome, open Kuro, tap the ⋮ menu, then Install app (or Add to Home screen).

iPhone and iPad

In Safari, open Kuro, tap the Share button, then Add to Home Screen and Add.

Mac

In Safari, open Kuro and choose File → Add to Dock. In Chrome, click the install icon at the right end of the address bar.

Windows and Chromebook

In Chrome or Edge, click the install icon at the right end of the address bar.

Back up the library

Drawings are saved only on the device. If the browser's data is cleared, or Kuro is uninstalled, the library goes with it. iPhones and iPads can clear a website's data on their own after a while without use, so back up there most of all.

  1. Open the Library and find Back up your library.
  2. Tap Save a backup file. Kuro saves a file named like kuro-library-2026-11-26.json. Keep it somewhere safe, such as your files app or cloud drive.
  3. To bring the drawings back, on this device or a new one, tap Load a backup file and choose that file. Drawings already in the library are skipped, so nothing doubles up.

Keys and tokens are never in a backup file. After loading a backup on a new device, add your key or Cloudflare account again in Settings.

Keeping keys safe

  • Keys and tokens are saved only on this device. Your Gemini key goes straight to Google. Your Cloudflare token goes through Kuro's server on its way to your own account, and is never saved or logged. More on the Privacy page.
  • Don't share a key or token. If you think someone has seen one, delete it in Cloudflare or AI Studio and make a new one.
  • Remove all my keys in Settings takes every key and token off this device, for example before giving the device to someone else.
